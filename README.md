# NexuStream

Repository per il progetto di Programmazione Web/Mobile

## Guida:

### Frontend

Dentro `ionic-frontend`, per il serve:

```sh
ionic serve --configuration=lang
```

dove `lang` è il linguaggio desiderato tra `it` ed `en`.

Per la build:

```sh
ionic build
node frontend.cjs
```

### Backend

Dentro `express-backend`:

```sh
npm run dev
```
